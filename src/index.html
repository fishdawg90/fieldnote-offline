Setup & phone test
  1. Download on Wi-Fi, keeping this page open.
  2. Run Test sample; expect “my fellow Americans”.
  3. Use Chrome’s menu to install or add to home screen.
  4. Turn on airplane mode, reopen and test again.
  5. Record a short note, check playback, then export.

English clips up to two minutes. Models run locally; no API or upload. Base needs its own download; Changing models also changes waiting notes. Tiny stays available unless you remove its download. Browser data removal deletes models and records. The phone may suspend processing when the screen is locked.

Export & backup
